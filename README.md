# ICPC solutions

Contest programs read from **stdin** and write to **stdout**. Do not prompt for input.

For now we are solving **problem 1**.

## Solution

Write your solution in `solution.py`. Read input with `sys.stdin` (or `input()`), then print only the required answer. Match the problem’s output format exactly.

## Input

Copy the problem’s sample (or your own test) into `input.txt`.

## Run

```bash
python3 solution.py < input.txt
```
